# HPLC Figure Bench

*Note: Application behavior documented here is based on inspection of the source code (`hplc-figure-bench(WF1.13).html`). No actual browser testing has been performed.*

## Purpose and Main Workflows
HPLC Figure Bench is a single-file HTML application for generating purification figures and summarizing protein purification workflows.

It supports two main modes:
*   **Project Mode:** Allows users to document an entire purification project across multiple steps (e.g., construct, transformation, expression, lysis, chromatography columns, cleavage, and final sample). The figure, summary, and methods text build progressively.
*   **Quick-Figure Mode:** A fast, stateless mode to create a figure from dropped data without creating a full project.

## How to Open on Windows
As a single HTML file, you can run the application locally on Windows by double-clicking `hplc-figure-bench(WF1.13).html` to open it in your default web browser, or by dragging and dropping the file into an open browser window. (This launch method is inferred from the file extension and typical OS behavior).

## Supported Inputs and Exports
**Inputs:**
*   **Chromatography Data:** `.csv`, `.tsv`, `.txt`, `.zip` (e.g., UNICORN 7 result archives), `.asc`, `.dat`, `.arw`, `.xy`, `.json`.
*   **Gel Images:** PNG, JPEG, TIFF, or other browser-supported image formats.
*   **Sequences:** GenBank (`.gb`, `.gbk`, `.genbank`, `.ape`, `.dna`) and PDB files (`.cif`, `.mmcif`, `.pdb`, `.ent`).
*   **NanoDrop Readings:** Text and CSV exports.
*   **Project Files:** `.json` project files generated by this tool.

**Outputs:**
*   **Figures:** Copy to clipboard as SVG, or save as SVG or PNG (adjustable dpi). Multiple figures can be saved as a ZIP archive.
*   **Data Summaries:** Summary tables, band size estimates, and peak integration tables can be saved as CSV files.
*   **Project Files:** The complete state of a project can be exported as a single JSON file.

## Protein mg from the UV area
*   **Formula:** mg = A280 area (mAU·mL) / 1000 / (A280 of 1 mg/mL × UV path in cm).
*   **AU traces** are shown and integrated in mAU.
*   **Runs exported in minutes** are converted to mL with the run's flow rate, read from the file or typed under Flow. With no flow, no UV mg is given, and the run card says why.
*   **Only the 280 nm curve** gives a mass. Other wavelengths (for example 260 nm) show the area but no mg.
*   **UV path:** when the file does not record it, the app assumes 2 mm (the usual ÄKTA monitor) and says so on the run card, in the peak table, under the summary table and in the methods. HPLC flow cells are often 10 mm, so enter the real value on the run card.
*   **Peak and pool areas** use the whole run, after smoothing and baseline, so zooming or cropping the plot never changes them.

## Storage and Backups
*   **Browser Storage:** The application uses `localStorage` for user settings, SEC calibrations, and custom protein lists. It uses `IndexedDB` to store projects locally in the browser.
*   **Host-Dependent Storage:** The code includes integration with an external environment (`window.claude`), which can provide cloud database and asset storage if the application is hosted there.
*   **Project Backups:** Users can manually download projects as JSON files using the "Export file" option to back up or move projects.

## External Libraries and Network Dependencies
The application fetches resources over the network for specific features:
*   **Fonts:** Loads "Instrument Sans" from Google Fonts (`fonts.googleapis.com` and `fonts.gstatic.com`).
*   **TIFF Gel Images:** Loads `pako` 2.1.0 from cdnjs (`cdnjs.cloudflare.com`) and `UTIF` 3.1.0 from jsDelivr (`cdn.jsdelivr.net`) the first time a TIFF image is opened.
*   **PDB Entries:** Fetches structure files directly from the RCSB Protein Data Bank (`https://files.rcsb.org/download/`) when a PDB code is requested.
